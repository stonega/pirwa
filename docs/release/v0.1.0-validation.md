## Build fixes and acceptance scope

The earlier hosted native failure came from Git's container ownership check;
the shell pipeline continued after `git archive` failed. CI now trusts only its
workspace and writes the archive before compressing it with fail-fast shell
behavior.

The initial hosted Flatpak preflight exposed an automatic `lib64` install
directory not searched by the following module. Every bundled Meson module now
sets `libdir=lib`, matching Flatpak's library/module paths across builder versions.
The failed preflight and corrected successful runs are retained in Actions.

This verifies publication and the listed automated checks. The user authorized
the first release with the [documented known limitations](v0.1.0.md#known-limitations).
Physical input, audio/accessibility, broader real-host integration, Windows
installation acceptance and remaining performance targets continue as follow-up;
publication does not mark those checks passed.
