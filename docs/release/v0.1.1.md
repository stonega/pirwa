# Pirwa v0.1.1

This patch fixes the machine viewer becoming empty when returning to Pirwa after
using another application. Switching to another machine and back is no longer
needed to refresh the display.

## Fixes

- Refresh the current guest frame when the viewer regains focus, resumes from
  compositor suspension, or maps again, even without a new SPICE damage event.
- Show connection progress and recover automatically if an established SPICE
  display surface disappears. Foreground viewers can wake an idle display;
  missing frames fall back to the existing reconnect timeout and backoff.
- Preserve healthy display connections and guest resolution during refresh.

Regression coverage checks rendered pixels after reactivation, repeated display
surface loss, foreground wake-up, timeout recovery, and viewer cleanup.

## Downloads and installation

Download `pirwa_0.1.1-1_amd64.deb`, `pirwa-0.1.1-1.fc45.x86_64.rpm`, or
`io.github.stonega.Pirwa-0.1.1-x86_64.flatpak` from this release. Source and debug
packages, `release.json` provenance, and `SHA256SUMS` are also included.

Fedora users with `stonegate/pirwa` enabled can update with `sudo dnf upgrade pirwa`.
Verify downloaded assets with `sha256sum -c SHA256SUMS`.

Package requirements and installation instructions are in the
[package guide](https://github.com/stonega/pirwa/blob/v0.1.1/docs/release/publishing.md).
The [v0.1.0 known limitations](https://github.com/stonega/pirwa/blob/v0.1.0/docs/release/v0.1.0.md#known-limitations)
continue to apply.
