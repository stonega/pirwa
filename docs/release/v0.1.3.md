# Pirwa v0.1.3

This patch fixes network traffic reporting with the host proxy and simplifies
the live usage header.

## Fixes and improvements

- Show receive and transmit rates for Session machines using the host proxy.
  Pirwa reads traffic counters from its gateway when libvirt does not provide
  them. Idle connections show zero traffic instead of unavailable statistics.
- Show only live CPU, RAM and network usage in the header, using the desktop
  monospace font. Remove the configured CPU count and RAM from the header,
  and omit the RSS and `/s` suffixes from the readings. Network values still
  represent rates in bytes per second.
- Show machine removal progress below its name, matching startup progress
  and using the theme's destructive color.

## Updating

After updating, fully shut down and start any machine already using the host
proxy to load the new gateway counters. Rebooting inside the guest keeps its
existing gateway running.

## Downloads and installation

Download `pirwa_0.1.3-1_amd64.deb`, `pirwa-0.1.3-1.fc45.x86_64.rpm`, or
`io.github.stonega.Pirwa-0.1.3-x86_64.flatpak` from this release. Source and debug
packages, `release.json` provenance, and `SHA256SUMS` are also included.

Fedora users with `stonegate/pirwa` enabled can update with `sudo dnf upgrade pirwa`.
Verify downloaded assets with `sha256sum -c SHA256SUMS`.

Package requirements and installation instructions are in the
[package guide](https://github.com/stonega/pirwa/blob/v0.1.3/docs/release/publishing.md).
The [v0.1.0 known limitations](https://github.com/stonega/pirwa/blob/v0.1.0/docs/release/v0.1.0.md#known-limitations)
continue to apply.
