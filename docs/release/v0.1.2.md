# Pirwa v0.1.2

This release fixes machine name collisions and installation media ejection,
and improves the creation flow and machine controls.

## Fixes and improvements

- Create multiple machines with the same display name, including from the same
  installation image. Each machine has its own UUID, internal libvirt name and
  storage. Renaming updates the display label while preserving that identity.
  Existing machines keep their definitions until explicitly edited.
- Fix locked installation media ejection, confirm ejection, and show progress
  directly in the eject button.
- Disable Secure Boot by default for new Linux guests using UEFI. The Windows 11
  Secure Boot requirement remains in place.
- Add icons to the Image, Name, Config and Boot steps, and align creation progress
  with the machine start presentation.
- Improve creation heading readability with desktop fonts, including Noto Sans
  CJK HK, while retaining native title sizes and natural letter spacing.
- Show machine icons in console status, refresh the application icon and add a
  sunglasses avatar expression.
- Place Force Stop above Remove and show it in the destructive action color.

## Downloads and installation

Download `pirwa_0.1.2-1_amd64.deb`, `pirwa-0.1.2-1.fc45.x86_64.rpm`, or
`io.github.stonega.Pirwa-0.1.2-x86_64.flatpak` from this release. Source and debug
packages, `release.json` provenance, and `SHA256SUMS` are also included.

Fedora users with `stonegate/pirwa` enabled can update with `sudo dnf upgrade pirwa`.
Verify downloaded assets with `sha256sum -c SHA256SUMS`.

Package requirements and installation instructions are in the
[package guide](https://github.com/stonega/pirwa/blob/v0.1.2/docs/release/publishing.md).
The [v0.1.0 known limitations](https://github.com/stonega/pirwa/blob/v0.1.0/docs/release/v0.1.0.md#known-limitations)
continue to apply.
